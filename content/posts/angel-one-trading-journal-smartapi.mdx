Angel One's app tells you what happened today. It doesn't tell you that your Bank Nifty trades have lost money four Mondays out of five, or that charges took 35% of last month's gross profit.

For that you need your trades in a journal, every day, without typing them. This guide walks through connecting Angel One to WickLog with SmartAPI, including the one limitation you need to plan around.

## The One Limitation: Today's Trades Only

**Angel One's API returns only the current day's tradebook, so WickLog can import each day's trades only on that day.** Holdings and open positions sync at any time, but closed intraday trades from previous days can't be fetched later.

In practice:

- **Sync once every trading day,** after the market closes at 3:30 PM IST.
- **Missed a day?** Those trades won't come through sync. Add them with WickLog's Excel template or the manual trade form.
- **Older history:** bring it in with the template once, then sync daily going forward.

If daily syncing doesn't fit your routine, a broker whose API provides trade history, like Zerodha Kite or Dhan, is easier to journal. Both are fully supported in WickLog.

## Step-by-Step: Connect Angel One to WickLog

### Step 1: Create a SmartAPI app

**Log in to the SmartAPI developer portal with your Angel One credentials and create a new app.** Give it a name such as "WickLog", choose the trading API type, and enter a redirect URL if asked. When the app is created, copy the **API key**.

{/* TODO screenshot: SmartAPI developer portal create-app form with app name and API key shown */}

### Step 2: Enable TOTP and save the secret

**Enable TOTP for SmartAPI and save the TOTP secret, not just the 6-digit code.** On the SmartAPI enable-TOTP page, enter your client ID and PIN, verify the OTP sent to your registered mobile and email, and you'll see a QR code.

Most people scan the QR with an authenticator app and stop there. WickLog needs the **secret key** behind the QR code, usually shown as a text string alongside it, so it can generate a fresh login code at each sync.

### Step 3: Enter the credentials in WickLog

**In WickLog, open Settings, go to the Connect tab, choose Angel One and enter four values: API key, client code, PIN and TOTP secret.** They're encrypted in your browser before they're stored, and they're never sent back to the browser afterwards.

{/* TODO screenshot: WickLog Settings > Connect with the four Angel One fields */}

### Step 4: Run your first sync

**Click sync after market close.** WickLog logs in through SmartAPI and imports:

- **Today's tradebook,** with fills matched into complete trades
- **Holdings and open positions,** shown as open trades with live prices
- **RMS margins:** free cash, utilised margin and holdings value in your capital ledger

### Step 5: Confirm entry dates on open positions

**Open positions created from Angel One holdings or positions are flagged "entry date estimated".** The snapshot doesn't always include when you first bought. Set the real date so holding periods and monthly P&L are correct.

### Step 6: Make the daily sync a habit

**Tie the sync to something you already do after 3:30 PM,** like writing your journal entry. Sync, check the day's net P&L on the dashboard, write two lines in the journal. Five minutes.

## Is It Safe to Store SmartAPI Credentials?

**WickLog only reads data and never places, modifies or cancels orders, but the combination of API key, PIN and TOTP secret is powerful, so understand what you're storing.** Together they can log in to your SmartAPI session, which supports trading.

What we do:

- **Read-only use.** WickLog only calls what it needs to read trades, holdings, positions and margins.
- **Encryption at rest.** All four values are encrypted in your browser before storage and never returned to the browser.
- **Removal on lapse.** If WickLog Pro ends, broker connections are deleted automatically.

What you control:

- **Use a dedicated SmartAPI app** for WickLog rather than one shared with an algo platform.
- **Revoke at any time** by deleting the app in the SmartAPI portal or resetting TOTP. WickLog can't sync after that.

## Common Mistakes & Troubleshooting

### "Login failed" on sync

Usually one of four values is wrong. The most common mistake is entering a 6-digit TOTP code instead of the TOTP **secret**. The code changes every 30–60 seconds; the secret doesn't.

### "Yesterday's trades are missing"

Angel One's API only provides the current day's tradebook. Add missed days with the Excel template or manual entry, and sync daily from now on.

### "Sync stopped working after I reset my PIN"

Update the PIN in WickLog's Connect settings. The same applies if you regenerate the API key or reset TOTP.

### "Net P&L doesn't match Angel One's P&L"

WickLog applies Angel One's brokerage formula plus STT, exchange fees, SEBI fees, stamp duty and GST to each trade, on rates in force since April 2026. Compare against your contract note, and mark options exercised at expiry with the "options exercised" flag so STT is calculated correctly.
